CHORD ATLAS MESIN AI LOKAL
1) Pasang Python 3.10 (64-bit) dan FFmpeg
2) Klik INSTALL_WINDOWS.bat (sekali)
3) Klik START_WINDOWS.bat tiap akan menggunakan Piano AI Studio
4) Buka CHORD ATLAS di GitHub Pages > Transkripsi Lagu > Piano AI Studio
5) Opsional, untuk AI generatif pasang Ollama dan model qwen2.5:3b
CATATAN: Mesin AI berjalan hanya di PC ini. GitHub Pages tetap hanya tampilan.
